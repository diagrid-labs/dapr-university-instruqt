Time to run the event planner for real. You'll create a Catalyst project, run the agent, and trigger it once. This challenge takes about 6 minutes.

> [!IMPORTANT]
> This challenge uses two terminals: *Terminal* for running the agent, and *Terminal 2* for triggering it. When you use the *Run* button on a command, select the matching terminal from the dropdown that appears.

### What you'll learn in this challenge

- How to create a Catalyst project and agent from the CLI
- How to run the agent with `diagrid dev run`
- What the crash looks like from both terminals
- Why the workflow survives even though the app that started it just died
