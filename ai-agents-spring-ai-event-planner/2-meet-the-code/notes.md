This challenge is pure reading, no running yet. You'll open three small Java files and see how a `ChatClient` bean, its tools, and the crash line fit together. This challenge takes about 6 minutes.

### What you'll learn in this challenge

- How a `ChatClient` bean becomes durable and gets registered as an agent, with no application logic changes
- Why the three tools are Spring beans rather than per-call tools
- Where the deliberate crash lives and why it uses `halt()` instead of `exit()`
- Why this quickstart needs no API key by default
