In this challenge you'll run two apps that have the same code and read from the same secret store. One of them reads a secret. The other asks for the same secret and is told no.

If you need more information about secret scoping during (or after) the challenge, visit the [Dapr Docs](https://docs.dapr.io/operations/configuration/secret-scope/).
