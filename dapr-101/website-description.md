Dapr takes the plumbing out of distributed applications, so you can focus on your own code. This lab is the quickest way to see how it works, hands on, without installing anything.

In this 30-minute lab you'll start with what Dapr is and why teams use it. Then you'll use the Dapr CLI to look at your local setup and run the Dapr sidecar. You'll save and read state through the State Management API, and inspect the stored records in the Dev Dashboard.

Next you'll run two applications that call each other with service invocation, and two applications that exchange messages through a message broker with pub/sub. Pick the language you prefer: .NET, Python, Java, or JavaScript. The Dapr building blocks stay the same.

You'll finish knowing how Dapr works, how to run apps with the Dapr CLI, and how the State Management, Service Invocation, and Pub/Sub APIs fit together.
