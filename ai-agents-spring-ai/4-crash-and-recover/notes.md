This is the payoff. You're going to kill the app mid-booking, restart it, and prove the same request attaches to the resumed run instead of booking twice. This challenge takes about 8 minutes.

> [!IMPORTANT]
> This challenge uses two terminals: *Terminal* for running the app, and *Terminal 2* for booking and killing it. When you use the *Run* button on a command, select the matching terminal from the dropdown that appears.

### What you'll learn in this challenge

- How to simulate a hard process kill mid-call
- How a caller-owned instance id lets a retry attach to a resumed run
- How to prove a recovered booking is not repeated
- Why idempotency is what makes a retry safe, not just durability
