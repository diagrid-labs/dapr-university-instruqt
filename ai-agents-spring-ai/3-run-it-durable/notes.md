Time to run the booking agent for real. You'll create a Catalyst project, run the agent, and book a reservation end to end. This challenge takes about 7 minutes.

> [!IMPORTANT]
> This challenge uses two terminals: *Terminal* for running the agent, and *Terminal 2* for booking. When you use the *Run* button on a command, select the matching terminal from the dropdown that appears.

### What you'll learn in this challenge

- How to create a Catalyst project and agent from the CLI
- How to run the agent with `diagrid dev run`
- What a durable booking call looks like end to end
- How to find your agent's workflow run in the Catalyst dashboard
