This challenge is pure reading, no running yet. You'll open three small Java files and see exactly how the durable advisor, the instance id, and the slow tool fit together. This challenge takes about 6 minutes.

### What you'll learn in this challenge

- How a `ChatClient` bean becomes durable with no application logic changes
- How a caller-owned instance id becomes an attach handle for retries
- Why the booking tool has to be a Spring bean, not a per-call tool
- Where the OpenAI model and durability settings are configured
