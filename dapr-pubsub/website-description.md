Sending a message is easy. Knowing how it is delivered, wrapped, routed and retried is what makes a pub/sub system reliable.

In this 45-minute lab you'll use Dapr pub/sub from .NET, Python, or Java. You'll compare declarative and programmatic subscriptions, then receive messages over a streaming subscription without exposing an endpoint. You'll see how CloudEvents wrap your messages and how to publish raw payloads instead.

Next you'll publish and subscribe in bulk, route messages by content, and send failed messages to a dead-letter topic after retries. Finally, you'll swap Redis for RabbitMQ by changing only YAML, while the application code stays exactly as it was.

You'll finish knowing how to choose a subscription type, control the message format, handle failures, and change brokers without a rebuild.
